# 💡 Prompt 技巧

> 学会和 AI 对话，才能让 AI 真正为你所用。

## 核心原则

### 1️⃣ 清晰明确

❌ 差的 Prompt：
```
帮我写个文案
```

✅ 好的 Prompt：
```
帮我写一个朋友圈文案，主题是介绍一款新的 AI 笔记工具，目标读者是知识工作者，语气轻松有趣，100字以内
```

### 2️⃣ 给 AI 设定角色

```
你是一个资深的内容营销专家，有10年社交媒体运营经验...
```

### 3️⃣ 提供示例

```
请按照以下格式回答：
- 问题分析：
- 解决方案：
- 注意事项：
```

### 4️⃣ 分步骤提问

复杂任务拆解成多个步骤，效果远好于一次提问。

## ✍️ 万能公式

```
角色 + 任务 + 上下文 + 格式要求 + 示例
```

**例子：**
```
你是一个资深程序员（角色），帮我 review 这段代码（任务），
这是一个 Python 后端项目，使用 FastAPI 框架（上下文），
请指出代码中的问题并给出改进建议，用列表格式输出（格式要求）。
```
