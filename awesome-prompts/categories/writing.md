# ✍️ 写作助手 Prompt

> 让 AI 成为你的写作搭档 — 文章、文案、创意写作

---

## 📝 万能写作框架

### Prompt

```
你是一个专业的写作助手。请根据以下要求创作：

主题：[填写主题]
目标读者：[填写读者群体]
字数要求：[填写字数]
语气风格：[正式/轻松/幽默/专业]

请按以下结构输出：
1. 引人入胜的开头
2. 核心内容（分点阐述）
3. 有力的结尾
```

### 使用场景
- 公众号文章
- 博客文章
- 产品文案

---

## 📢 朋友圈文案

### Prompt

```
请帮我写一条朋友圈文案：
主题：[填写主题]
我希望传达的感觉：[填写感觉]
字数控制在100字以内
语气：[轻松/文艺/幽默]
```
