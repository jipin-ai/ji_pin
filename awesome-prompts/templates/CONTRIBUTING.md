# 🤝 贡献指南

欢迎贡献优质 Prompt！感谢你让这个库变得更好 🙌

## 提交流程

1. Fork 本仓库
2. 在 `categories/` 下找到对应分类文件
3. 按格式添加你的 Prompt
4. 提交 PR

## 格式要求

每个 Prompt 请包含：
- **名称**：简短描述 Prompt 的作用
- **描述**：一两句话说明用途
- **适用场景**：什么情况下用这个 Prompt
- **完整内容**：可复制的 Prompt 文本
- **示例**（可选）：使用效果或截图

## 注意事项

- 确保 Prompt 已被实测有效
- 不要提交涉及违法/违规的内容
- 英文 Prompt 也可提交（标注语言）

感谢你的贡献！🎉
