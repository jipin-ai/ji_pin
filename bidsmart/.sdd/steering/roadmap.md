## P2 里程碑 (下一阶段)

| 优先级 | 功能 | 说明 |
|--------|------|------|
| **P2-1** | PostgreSQL 迁移 | 从 SQLite → PostgreSQL，支持并发写入和生产级可靠性 |
| **P2-2** | 项目成员 RBAC | ProjectMember 模型接入服务层，实现项目级细粒度权限 |
| **P2-3** | WebSocket 支持 | 审查进度实时推送，替代当前轮询方案 |
| **P2-4** | 审查报告导出 | PDF/Word 格式合规审查报告生成与下载 |
| **P2-5** | FAISS 向量索引 | 知识库从 numpy dot-product → FAISS，支持 10万+ 文档检索 |
| **P2-6** | 移动端适配 | 响应式布局优化，支持手机/平板查看审查结果 |

## P3 远期规划

- 在线协同编辑 (多用户同时编辑投标文件)
- 标书自动生成 (AI 驱动模板填充)
- 公有云 SaaS 多租户架构
- 多语言招标文件审查
- 容器化部署 (Docker/K8s)
- CI/CD 管线自动化
