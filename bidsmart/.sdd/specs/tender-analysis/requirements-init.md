# 标前招标分析 — 需求初始化

## 项目描述

为 BidSmart 新增标前分析（Pre-bid Tender Analysis）功能。用户上传招标文件后，AI 自动提取所有评审要求，按废标/重要/一般三层分类，生成结构化分析报告，辅助投标书编写人系统性地编写投标文件，避免遗漏关键条款。

## 当前状态

- 审查管线已支持招标文件解析和条款提取（514条/份）
- 现有 `_classify_weight()` 仅基于关键词做简单分类（red/yellow/amber）
- 无标前分析端点，无三层分类能力

## 期望变更

1. 新增 `/ai/analyze-tender` 端点
2. LLM 全文一次性三层分类（非逐条，1次API调用）
3. 输出结构化 JSON + 可选 Markdown 报告
4. 支持文件上传和已存储文档 ID 两种输入方式
