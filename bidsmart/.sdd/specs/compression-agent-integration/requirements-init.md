# Compression Agent Integration — Requirements

## 项目描述

将已验证的五层渐进式上下文压缩引擎集成到 BidSmart（标书智审），同时支持 100MB+ 大文件分块处理，并将法规知识库迁移为 SKILL.md 格式。

## 当前状态

- BidSmart v0.7.8 是 pipeline 模式：4阶段流水线（提取→匹配→审查→聚合）
- 没有 Agent Loop，无上下文累积，无压缩机制
- 文档全量加载到内存（>100MB 时 OOM 风险）
- 每条 AI 调用上下文截断 3000-4000 字符
- 4份法规文档存在 SQLite KB 中，但审查时未引用
- 压缩引擎已验证（独立模块，3.5x-5.2x 压缩比）

## 期望变更

### 功能概述
1. 集成压缩引擎到 BidSmart 的 Agent 审核模式
2. 支持 100MB+ 文档的自动分块和按需检索
3. 新增 Agent 模式（工具调用 + 多轮审核），保留旧 pipeline 兼容
4. 法规模板 SKILL.md 化
5. 针对大文件场景配置压缩参数

### 目标用户
- 标书审核员：需要多轮追问的交互式审查
- 评标专家：需要引用法规依据的深度分析
- 系统管理员：需要可控的上下文管理
