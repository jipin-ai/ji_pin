### 关于

CTGC 创始人。研究多 Agent 协作管道的编排、状态管理和通信协议。

目前聚焦三个方向：

- **Agent 管道引擎** — 用 30 行 YAML 定义多 Agent 协作流程。SQLite 状态机，零外部依赖
- **数据资产标准化** — GB/T 47950-2026 数据资产登记与 ABS 证券化流程设计
- **A2A 通信协议** — 基于 Hermes Agent 的 Agent-to-Agent 通信拓扑
